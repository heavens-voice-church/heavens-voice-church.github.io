# 하늘소리교회 (Heaven's Voice Church) 

기독교대한복음교회 하늘소리교회 공식 웹사이트 Repository입니다.

## 🛠️ 기술 스택
- **프레임워크**: React 19, TypeScript
- **빌드 도구**: Vite 6
- **스타일링**: Tailwind CSS v4
- **아이콘**: Lucide React

## 🚀 로컬 개발 및 실행

**요구사항:** Node.js (v18 이상 권장)

1. 의존성 설치:
   ```bash
   npm install
   ```

2. 로컬 개발 서버 실행:
   ```bash
   npm run dev
   ```

3. 프로덕션 빌드 및 타입 검사:
   ```bash
   npm run build
   ```

4. 타입 검사 (린트):
   ```bash
   npm run lint
   ```
